## 外网实测发现与处理

- 本机直接访问部分 `trycloudflare.com` 临时网址时出现连接关闭；使用本机已有代理后成功。故不能承诺朋友所在地的网络都能直连。
- 上游构建会在首屏同时加载大量独立模块，曾触发转发服务的 HTTP 429。现改成每个客户端最多 6 个并发预加载请求，保留原有模块边界，并提供进度和失败重试。
- 新构建会刷新预加载缓存；同一构建重连可复用缓存。游戏加载等待时间延长，避免慢网被误报成扩展损坏。
- 外网验证是从本机经公网入口折返到本机服务，不等同于多地区、多运营商的真人联机验收。

## 首次和朋友约局时检查

1. 用“外网联机.cmd”启动，4 位朋友分别用各自设备、网络打开临时网址。
2. 检查口令错误提示，正确加入后等待全部入座并开始。
3. 确认各自身份、手牌和出牌提示；实际完成一局，重点观察手机点牌、目标选择与无懈响应。
4. 普通玩家切后台或关页后，用原浏览器原网址回来；房主应保持等待，恢复原座位及手牌。
5. 房主结束重开后重新加入；最终关闭命令窗口，确认临时网址不能再进入游戏。

真实 Android / iPhone 的触控、切后台恢复和不同网络质量尚未实机验证。胶国杀武将已接入首轮实现，复杂技能组合仍需实战校准；主机崩溃续局、跨设备身份恢复不在本版实现范围内。
