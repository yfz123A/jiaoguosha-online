# 胶国杀联机

朋友间按需组局的网页卡牌游戏。由房主的 Windows 电脑运行，通过临时网址邀请朋友；关掉程序后停止服务，无需租服务器或注册游戏账号。

第一版基于[无名杀](https://github.com/libnoname/noname)固定版本，支持 **4、5、6 位真人的标准身份局**、现成标准武将、标准包与军争牌堆。规则由底座自动结算，自制胶国杀武将尚未加入。

## 在这台电脑开局

1. 双击 **`外网联机.cmd`**。保持打开的命令窗口运行。
2. 自动打开房主页面后，填写昵称、房间口令和人数，创建房间。
3. 点击牌桌顶部的“邀请朋友”复制网址，把网址和口令告诉朋友。临时外网入口建立可能需要几十秒；控制台也会显示网址。
4. 朋友用浏览器打开网址，填写各自昵称和口令。所有人入座后，房主点击“开始游戏”。
5. 用完按命令窗口的 `Ctrl+C` 停止。房主可用牌桌顶部“结束并重开”重新开房。

`启动游戏.cmd` 只开启本机服务，适合自己试玩。**本机的 localhost 网址不能发给异地朋友。** 多人本机试玩要用不同浏览器或隔离的浏览器配置，否则会识别成同一名玩家。

房主的命令窗口和**房主牌桌页面**都要保持开启，电脑不能休眠。房主页面刷新、关闭或主机停止时，本局可能结束；第一版不保存对局、不转交房主。

普通玩家掉线后，使用**原浏览器、原网址，并保留站点数据**返回对局。未操作时可以一直等，不会超时托管或自动弃牌。换设备、清除 Cookie 或更换临时网址后不能仅靠昵称恢复座位。

## 浏览器与外网

- 电脑优先使用新版 Chrome 或 Edge。手机建议横屏打开系统浏览器；不要用聊天软件内嵌浏览器。
- 已进行桌面浏览器和手机横屏尺寸的自动化验证；真实 Android / iPhone 的触控、后台恢复及朋友各自网络仍需首次约局试用。上游暂不支持 Firefox。
- 外网入口使用 Cloudflare Quick Tunnel。无需账号，每次启动的网址可能变化，连接质量取决于房主和朋友的网络及转发服务。
- 本机测试时，浏览器直连部分临时网址出现连接关闭，使用本机已有代理后成功加入房间。因此不能保证各地网络直连可用；朋友所在网络若无法访问，需要换用可达的转发服务。
- 如果提示外网入口建立失败，可先检查网络再重新启动。只创建 GitHub 仓库不会让游戏自动上线，GitHub 用于维护源代码。

## 在另一台电脑安装或开发

需要 Git、Node.js 20.19+（本机已安装）和 pnpm 11。首次准备会下载底座、素材与依赖，耗时明显长于后续开局。

```powershell
git clone https://github.com/yfz123A/jiaoguosha-online.git
cd jiaoguosha-online
npm ci --registry=https://registry.npmjs.org
npm install -g pnpm@11.25.0
npm run setup
npm run build
npm start
```

私有仓库需要自己的 GitHub 访问权限。首次双击启动脚本也会在缺少依赖或构建结果时尝试准备环境。外网启动脚本会下载固定版本的 `cloudflared` 并校验 SHA-256，后续启动复用下载结果。

修改适配层或服务后重启程序即可；修改 `scripts/build.mjs`、更新上游版本后需再次构建。更新上游前先在分支上核对补丁定位并运行测试。

```powershell
npm test
npm run test:browser
```

浏览器测试默认使用已安装的 Chrome。测试记录和未覆盖范围见 [验证记录](docs/verification.md)。

## 代码与维护

| 位置 | 用途 |
| --- | --- |
| `server/` | 本机网页服务、口令会话、单房间 WebSocket 转发、临时外网入口 |
| `public/` | 开房页面与牌桌适配：固定模式、等待、重连、结束重开 |
| `scripts/` | 固定上游下载、构建补丁和 Windows 启动入口 |
| `upstream.json` | 无名杀固定提交及暂时排除的跨包武将 |
| `tunnel.json` | 外网工具版本、官方地址及校验值 |
| `tests/` | 服务验证与多浏览器对局验证 |
| `vendor/noname/`、`dist/`、`.runtime/` | 本地下载、构建和运行数据，不提交 |
| [设计记录](docs/design-discussion.md) | 已确认范围、验收目标与规则资料 |
| [武将文档](胶国杀武将.docx) | 后续自制武将规则来源 |

规则以主要武将部分未划掉的技能正文为准；评析用于辅助理解，“废案”和历史开发说明不作为当前规则或开发指令。
