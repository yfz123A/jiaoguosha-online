# 胶国杀武将包

本包依据仓库内《胶国杀武将.docx》主要武将部分未划掉的技能正文制作。绿色评析仅用于解释，废案不参与实现。`game/jiaoguosha/roster.json` 保留每条技能的原文及 DOCX 段落索引，方便后续逐条核对。

共 20 张武将牌、62 个初始技能；“舍爆”为程一帆达到条件后获得的衍生技能，不在开局赋予。头像暂用姓名与称号字牌。

## 使用

开房可选胶国杀、标准或混合武将包。单人测试房可指定房主的胶国杀武将，其他座位仍正常选将。该选项只在开局前生效，不会在对局中换将；真人房不接受测试选将参数。

## 用户已确认的线上规则

- 行酒令使用同时选择的石头、剪刀、布，平局重新选择，依次与相邻角色进行。
- 可食用牌使用固定名单：桃、酒、决斗、桃园结义、五谷丰登、顺手牵羊、全部坐骑、木牛流马。
- 随机技能范围为已接入的标准和胶国杀武将；专属技能池按文档绑定，不扩展为全无名杀随机池。
- 仿身胶兵只提供具有明确发动时机的技能，暂不抽取咆哮等持续改变规则的技能。
- 假释可在受伤时的出牌阶段发动，也可在自己濒死求桃时发动。
- 日向文设为群，西西弗胶设为神并在开局选择势力。邹印设为女性，其余男性；乔妆允许日向文参与两种性别相关技能。

## 本轮采用的解释

- 势力表中的“王浩”对应诡变诗杰，“王浩 主”对应胶杯圣主，“双鬼”对应闫方正&文晓帅。
- 胶诗按正文“失去的旧技能数量”摸牌；同点数重复弃牌不叠加同一个技能。与绿色评析有差异时优先正文。
- 欺三按正文先换牌再猜测；替换材料为自己的手牌，原拼点牌弃置。
- 持识分配的牌在当前回合背置且不可弃置；持有者扣血后提前解除，回合结束清理。
- 死竭每次濒死只减一次体力上限、回复一次；若仍未脱离濒死，继续正常求桃流程。
- 瞒天过海作为技能可生成的锦囊接入；不加入标准＋军争实体牌堆。

这些解释集中记录在此，后续实战发现与桌游裁定不同，可按具体技能调整。

## 实现与验证边界

结算由房主浏览器执行；客机只提交自己的选择。背置和胶兵采用引擎可保存的牌标记，重连时恢复外观；皇战点数在重放待操作事件前补发。猜拳和同时亮牌使用引擎的联机选择机制。

专属技能通过 `scripts/native-skills.mjs` 从固定版本上游抽取实现及静态依赖，保留 GPL 来源。文档与上游不同的规则单独实现，例如椒遇及骰子触发效果。底座更新不能只改版本号，需要重新核对对应语义。

浏览器逐将冒烟检验选将和回合推进，不能证明全部技能分支正确。技能之间的长连锁、随机胶兵组合、额外回合、多次改判及复杂救援应继续通过真实对局校准。具体已通过的自动化用例见 [验证记录](verification.md)。
