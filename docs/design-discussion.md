# 胶国杀线上联机设计讨论

## 已确认

- 主要场景：朋友异地通过互联网一起玩。
- 运行方式：用户自己的电脑在游玩时启动并保持开机联网，平时不运行；不租服务器。
- 加入体验：电脑和手机浏览器，最好打开链接即可加入。
- 对局规模：通常 4–6 人，全真人。
- 结算方式：以系统自动处理规则为目标。第二轮明确优先跑通游戏，自制武将技能的正确实现后置；第三轮确认先用无名杀现成武将和技能验证完整对局，再加入胶国杀武将。
- 第一版模式：标准身份局；不采用“各怀鬼胎”等身份变体。
- 武将规则来源：以主要武将部分未划掉的技能正文为准；评析用于辅助理解，冲突另行确认，“废案”和历史开发说明不作为有效规则。
- 外网连接：接受第三方免费转发服务及每次开局网址可能变化；具体服务须实测。
- 界面方向：沿用无名杀基本牌桌与操作，换成胶国杀内容，简化开房入口。
- 恢复目标：普通玩家短暂断线可重连并等待其回来；主机程序或房主游戏页面关闭后允许本局重开。不要求主机崩溃后恢复原局。
- 加入方式：昵称与房间口令，不需要账号。
- 第一版牌堆：沿用底座现成的标准包与军争牌堆，暂不定制牌堆。
- 等待行为：允许一直等待掉线或暂未操作的玩家，不自动代打、弃牌或因等待超时结束；房主可终止本局重开。
- 当前工作：讨论实现效果和设计，结合武将文档与无名杀源码评估方案。

## 首版体验与验收

本轮首版范围已收敛，后续实现以以下行为为验收目标。当前仅完成设计与源码只读核对，尚未实现或实测这些行为。

1. 用户在自己的 Windows 电脑启动程序，获得可分享的临时网址；结束游玩后可停止服务。
2. 朋友通过电脑或手机浏览器打开网址，使用昵称和房间口令加入，不注册账号。口令错误时不能进入对局。
3. 4、5、6 名真人均可开始标准身份局，使用现成武将与标准包、军争牌堆，完成选将、发牌、出牌、响应、伤害、死亡和胜负结算。
4. 界面保留无名杀牌桌与基本操作，入口面向熟人临时组局简化；手机操作需实机验证。
5. 普通玩家短暂断线后，在原浏览器保留站点数据的条件下能返回原座位，恢复其可见信息与当前选择流程。等待期间不能由程序自动代打或弃牌；房主可终止本局。
6. 主机程序或房主页面关闭后允许本局结束并重开，不要求保存原局或自动转交房主。
7. 自制武将的正确实现不阻塞首版联机验收，后续再逐项接入与验证。

## 后续验证与后置内容

- 外网转发的实际连接质量、网页资源加载和联机连接是否同时可达。
- 无名杀普通玩家重连能否满足目标，手机切后台后的实际行为。
- 第一版手机横屏布局与操作体验。
- 自制武将逐项实现、文本歧义裁定与复杂技能联机正确性后置，不作为先跑通对局的前提。
- 当前仍是设计讨论；尚未安装底座或编写游戏实现。

## 只读核对结果

以下是 2026-11-09 的资料核对，尚未经过本项目运行验证；用户已选择的范围以上文“已确认”为准。

- 武将文档“武将”至“势力分配表”前有 20 个武将条目，含变体与合体。正文也有删除线旧文；“废案”“附页”“实战反馈”“小程序开发”不应直接混入有效技能规则。绿色评析有与技能正文不一致的内容；第二轮已确认采用未划掉的主要技能正文。
- 文档提及“不臣之君”“各怀鬼胎”及“三国杀 OL 军争牌堆”，但未提供完整模式、胜利条件与牌堆定义。第二轮用户另行选定首版标准身份局，第三轮选定底座现成标准包与军争牌堆。
- 特殊机制包括向代煜的行酒令、程一帆按插画判定的可食用牌、文晓帅的背置手牌、西西弗胶的阶段交换，以及王浩的随机武将技能借用。首批武将选择应考虑这些机制的隐含依赖。
- [无名杀启动文档](https://github.com/libnoname/noname/blob/main/docs/how-to-start.md)分别提供网页与本地 WebSocket 联机服务的启动方法，因此按需启动有代码基础。仅启动联机服务不会自动提供网页及素材。
- [联机服务实现](https://github.com/libnoname/noname/blob/main/packages/server/src/server/createServer.ts)管理房间并在房主与成员间转发消息；房主连接关闭时会通知成员关闭并删除房间。因此沿用该路径时，主机进程及房主游戏会话都要保持运行，不能承诺现成支持房主迁移或崩溃恢复。
- [无名杀 README](https://github.com/libnoname/noname/blob/main/README.md)列出 Chromium >= 91、Safari >= 16.4，暂不支持 Firefox。手机实际布局、切后台和重连仍需测试。
- 第一轮曾建议先验证代表性自制技能；第二轮用户明确将技能正确实现后置，第三轮选择现成武将，因此先用底座基础对局验证联机链路。无名杀版本及具体部署方式仍待核验。
- [内核人数配置与重连](https://github.com/libnoname/noname/blob/main/apps/core/noname/library/index.js)已有身份局人数选项，涵盖 4、5、6 人，并有通过原玩家 ID 恢复场面的 reinit 机制；[联机入口](https://github.com/libnoname/noname/blob/main/apps/core/mode/connect.js)保存 reconnect_info。换浏览器或清除站点数据后的身份恢复不属于已验证能力，不能依靠昵称判定原玩家。
- [标准包](https://github.com/libnoname/noname/blob/main/apps/core/card/standard.js)与[军争包](https://github.com/libnoname/noname/blob/main/apps/core/card/extra.js)都有联机标识和牌堆列表。本轮选择现成包，不要求精确还原某一实体牌版本；实际包构成需在实现时记录。
- 已核对的加入房间界面及大厅 enter 路径未见口令验证，房间口令按需要补充核验与实现的功能规划，不能当作底座现成能力。大厅对于已开始房间存在旁观配置检查，普通玩家重连需连同房间配置一起测试。
- 本机已有可调用的 Git 2.55.0.windows.3、Node.js 20.20.2 和 pnpm 11.25.0；尚未安装项目依赖或下载底座。
