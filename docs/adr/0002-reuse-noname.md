# 复用无名杀的基础牌桌与操作

2026-11-09 用户选择沿用无名杀基本牌桌和操作方式，简化朋友之间的开房入口，逐步加入胶国杀内容。相较从头开发完整卡牌引擎和独立界面，此路线优先利用现有基础规则与联机能力，符合“第一版先跑起来，自制技能正确实现后置”的目标。

第一版固定无名杀 1.11.7 的提交 `351176e1e0cab4580229e69b7a197811c7bfc8a1`，仅构建标准身份、标准武将、标准与军争卡牌。源码和素材由安装脚本获取，具体补丁集中在 `scripts/build.mjs`，以便核对和更新上游。

网页通过本项目的只读静态服务提供，联机使用单房间 WebSocket 转发，房主浏览器执行游戏规则。公网入口只连接到此服务，不提供上游开发服务器的文件写入接口。口令会话、固定人数、无限等待及普通玩家重连由本项目适配层补足。

现成联机能力不代表所有自制技能天然兼容。接受沿用路径下主机程序或房主游戏页面关闭后重开本局，不要求首版实现房主迁移或主机崩溃恢复。
