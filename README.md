# 胶国杀联机

供朋友临时组局的网页卡牌游戏项目，计划复用[无名杀](https://github.com/libnoname/noname)的基础规则、牌桌与联机能力，逐步加入自制胶国杀武将。

**当前状态：已完成首版需求讨论与初步源码核对，尚未接入游戏底座或实现可运行版本。** 当前仓库用于维护规则资料、设计决策及后续代码。

## 首版目标

- 由发起者的 Windows 电脑按需启动，平时不运行，不租用服务器。
- 通过第三方转发提供临时网址，朋友用电脑或手机浏览器加入。
- 使用昵称与房间口令，无需注册账号。
- 支持 4–6 位真人进行标准身份局。
- 先使用无名杀现成武将、标准包与军争牌堆，自动结算完整对局。
- 沿用无名杀的基本牌桌与操作，简化组局入口。
- 普通玩家短暂断线后可重连；允许等待，不自动代打或弃牌。房主可终止本局重开。
- 主机程序或房主页面关闭后允许重开，不要求首版恢复原局。
- 自制胶国杀武将在基础联机跑通后逐项加入。

## 实现顺序

1. 接入并固定无名杀版本，跑通本机完整对局。
2. 补充房间口令与等待行为。
3. 打通网页资源和联机连接的外网访问。
4. 验证手机操作、普通玩家掉线重连及 4–6 人完整对局。
5. 逐步接入胶国杀武将及对应规则验证。

尚无启动命令；接入底座后在此补充环境准备和使用方法。房间口令、外网访问和重连体验均需要实际实现或验证，不能由上游具备联机功能直接推定已满足需求。
